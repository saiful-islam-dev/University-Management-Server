## 🚀 Introduction
**University Management Client** is an enterprise-level web application designed to simplify campus administrative workflows, student portals, and academic management. Powered by React 18, TypeScript, and Ant Design, it delivers a secure, responsive, and intuitive interface for students, faculty, and administrators alike.

---

## ✨ Features
- ⚡ **Lightning-Fast Performance**: Built with Vite 5 for quick load times and instant HMR.
- 🛡️ **Type-Safe Codebase**: Fully written in TypeScript for reliable data structures and compile-time error catching.
- 🎨 **Enterprise Admin Dashboard**: Styled using Ant Design (`antd`) components, form elements, and icons.
- 🔄 **Persistent State Management**: Driven by Redux Toolkit & Redux Persist for cross-session state retention (auth tokens, user preferences, etc.).
- 🧭 **Role-Based Navigation**: Protected dynamic routes and layouts managed with React Router DOM.
- 📝 **Interactive Forms**: High-performance form handling and validation with React Hook Form.
- 🔐 **JWT Authentication**: Client-side payload decoding (`jwt-decode`) to manage roles and session expiration.
- 🧹 **Strict Code Standard**: Pre-configured ESLint rules ensuring clean and reliable code structure.

| Technology | Purpose |
